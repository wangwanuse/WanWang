# Photography Portfolio Static Site

This is a plain HTML, SCSS, CSS, and JavaScript portfolio starter.

## Structure

- `index.html` - single-page portfolio viewer, index panel, info panel, and thumbs overlay
- `project.html` - redirect fallback to the portfolio
- `about.html` - redirect fallback to the portfolio
- `scss/main.scss` - source styles
- `css/main.css` - browser-ready stylesheet
- `js/main.js` - small project data helper
- `images/` - replace these placeholder images with your own work

## Edit

Open this folder in VSCode and edit the HTML files directly. Replace the SVG files
inside `images/` with your own images, then update the image paths in the HTML or
`js/main.js`.

## Deploy

Upload the folder to GitHub and import the repository into Vercel. Because this is
a static site, no build command is required.
